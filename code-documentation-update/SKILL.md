## Modes

| Mode                     | Trigger                                 | Behavior                                                                                                                                                                             |
| ------------------------ | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Update Documentation** | "update documentation", a scheduled run | Go through the entire codebase and update or generate comments on all classes, objects, and methods using the inline documentation style of the language the codebase is written in. |
